# CodeAlpha Hangman Game

## About the Project
This is a simple console-based Hangman Game developed using Python as part of the CodeAlpha internship.

## Features
- Random word selection
- Letter guessing
- Maximum 6 incorrect guesses
- Repeated guess detection
- Input validation
- Win and lose messages

## Technologies Used
- Python
- random module
- Lists
- Sets
- Strings
- Loops ("for" and "while")
- Conditional statements ("if-else")
- Functions
- Input validation

## How to Run
1. Install Python.
2. Download the hangman.py file.
3. Open a terminal in the folder containing the file.
4. Run the following command:

   python hangman.py
